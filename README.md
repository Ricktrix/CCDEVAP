# CCDEVAP
Online Ticketing System

Project Overview
Lorem ipsum Online Ticketing System is a responsive client-side web application prototype that simulates a modern airline booking platform. The system allows users to searcj flights, book reservations, manage bookings, view profiles, and access administrative interfaces through an intuitive and professional airline-themed user interface.

This project was developed as part of the CCDEVAP Machine Project (MCO) and focuses on frontend development using HTML, CSS, JavaScript, jQuery, and Boostrap.
